Add it in Zoho Mail

  1. Click Copy signature above.
  2. In Zoho Mail, open Settings (gear icon) → Signatures.
  3. Click + to add a new signature and name it, for example "Mufin".
  4. Click inside the signature box and paste (Ctrl + V, or Cmd + V on Mac).
    If the formatting looks off, use Copy HTML code instead and paste it with the editor's Insert HTML option.
  5. Under Associate Mail Address, choose your email address so it is added to every new email.
  6. Optional: tick Add signature to all my email replies so replies get it too.
  7. Click Save and send yourself a test email.

For the Zoho admin

  1. Keep mufin-email-logo.png in the same folder as this page. The signature picks it up automatically.
  2. Share this page with the team so each person can make their own signature.
  3. On a paid Zoho plan, you can instead set one signature for everyone: Admin Console → Organization → Signature Template → Configure template. Paste the HTML code there and swap the personal details for Zoho's placeholders (name, email, phone). Users then can't edit their signature.
